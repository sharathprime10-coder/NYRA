# Security Policy

## Supported Versions

Since this is a student/research project, there is no official Long Term Support (LTS) release. Only the latest commit on the `main` branch is supported for bug fixes and security patches.

## Reporting a Vulnerability

If you discover a security vulnerability within NYRA, please send an e-mail to the development team or open a Private Security Advisory on GitHub.

**Please do not report security vulnerabilities through public GitHub issues.**

## Disclaimer

This project is built for educational, research, and demonstration purposes. It is **not** intended to be deployed in a production environment with sensitive, confidential, or real user data without a full security audit. While we have implemented guardrails (such as RAG user isolation), there are no guarantees of zero data leakage or LLM hallucination.
